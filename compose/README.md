# Описание

| Пункт | Пакет | Назначение |
|---|---|---|
| БД | illuminate/database | Eloquent ORM + Query Builder без Laravel |
| Кеш | predis/predis | Клиент Redis для кеширования в памяти |
| XLS | phpoffice/phpspreadsheet | Генерация Excel-отчётов |
| PDF | dompdf/dompdf | Простая генерация PDF из HTML |
| E-mail | phpmailer/phpmailer | Отправка писем и рассылок |
| Тесты | hpunit/phpunit | Модульное тестирование |
| Облачное хранилище AWS S3 | aws/aws-sdk-php |Официальный AWS SDK для PHP. Содержит клиент S3 для загрузки/скачивания/удаления файлов, а также поддерживает другие сервисы AWS (SES, SQS, DynamoDB и т.д.).|
